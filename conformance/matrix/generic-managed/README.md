# `generic-managed` matrix

Link+run and refcount-balance coverage for a **generic container holding a managed
element**, across the two axes that hid the recent generics bug cluster. Cells are
GENERATED by `conformance/gen-generic-managed-matrix.py` (do not edit by hand);
`conformance/run.sh` auto-discovers every `.bn` / `main.bn` here.

## Axes (coordinate-addressed: `<site>/<element-kind>/<op>`)

- **site** — `inpkg` (the generic `Holder[T]` is defined in the cell's `.bn`) vs
  `xpkg` (a per-cell `pkg/gh.bni` body-included `Holder[T]`, consumed + monomorphized
  in `main.bn`). This is the single most bug-dense axis: in-package coincidentally
  aligns the mangled call/def prefixes; cross-package diverges — where `8d9e7577`
  (managed-element dtor mangling), `c14dd95e`/`aba92526` (named-wrapper element
  helper), and `1007` lived.
- **element-kind** — `managed-ptr` (`@Counter`), `managed-slice` (`@[]int`),
  `named-wrapper` (`type Buf @[]@Box`), `named-array` (`type NArr [3]@Box`), … .
- **op** — `balance` (hold + observe refcount) / `empty` (never-populated destroy).

Each cell defines its OWN generic container inline — it never imports
`pkg/stdx/containers/*` (not on the conformance-imports whitelist); the `xpkg`
fixture mirrors `conformance/995`'s `gholder.bni`.

## Invariants

- **refcount balance** (`balance` cells) — a mortal managed observable held in the
  container gains exactly one ref and is released when the container drops:
  `rt.Refcount(po) == before+1` while held, `== before` after. Relative form, so
  the `.expected` column `[1, <value>, 1]` is baseline-independent. Catches
  leak / use-after-free of the element (the mangler bugs manifested as either a
  link failure OR, once linked, a dropped/duplicated element ref).
- **links + runs** (all cells) — no undefined-symbol (compiled) / extern-not-found
  (VM). The `empty` cells specifically force the element **dtor/copy helper to be
  emitted for a never-populated container** — the exact case that hid `c14dd95e`
  (dtor) and `aba92526` (copy).

## Which landed bug each sub-grid regression-guards

| cell | guards |

## Status / scope

First increment = the bug-dense core (the 3 element kinds above × both sites).
Planned follow-ups (see `explorations/plan-matrix-tests-generics-rtti.md`):
struct-with-managed-field / func-value / iface / array-of-managed / nested-generic
element kinds; `copy` and `destroy-populated` ops; the **method-value** operation
(`inpkg`/`xpkg`/call-result, mirroring `146`/`167`/`168`); and the **type-distinctness**
compile-error `.error` pair cells (array-length `[3]`vs`[5]` per `1017`, func-signature
`(int)uint`vs`(bool)uint` per `1016`). Second wave (gated on a minimal cell compiling):
method-expression, parameterized-receiver-impl and generic-constraint dispatch.

Mode scope: green under the six default modes + native x64/aa64. `native-arm32`
(`builder-comp_native_arm32_baremetal`) is an incomplete backend — any red there is
backend incompleteness (xfail with a note), not a generics finding.
