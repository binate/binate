# readonly matrix

The **`readonly` type-modifier transparency** member of the conformance matrix
family (`../README.md`). Coordinate-addressed:

    conformance/matrix/readonly/<operation>/<shape>.bn   (+ .expected)

Generated by `conformance/gen-readonly-matrix.py`.

## Axes & assertion

- **`<operation>`** — `scalar` (read a readonly scalar), `field-read` (read a
  struct field through a readonly value / ptr), `index` (index a readonly array),
  `method` (call a method / interface method on a readonly receiver),
  `pass-arg` (read a field inside a `readonly` parameter), `wrapper-order` (the
  modifier on the POINTEE — `@readonly Box` / `*readonly Box` — not the pointer),
  `alias` (method dispatch through an alias-typed receiver), `construct` (wrap a
  concrete value into a `readonly @Iface` target).
- **`<shape>`** — the inner shape the modifier wraps: scalar, named-scalar,
  value-struct, array, raw-ptr-to-struct, managed-ptr-to-struct, iface-value,
  managed-struct-with-method.

**Assertion:** a readonly view observes the SAME value as the corresponding
non-readonly access (value ops), and a non-mutating method/interface call on a
readonly receiver succeeds and matches the plain result (dispatch ops). One int
per lane, on every backend — `readonly` is layout-transparent, so a missed peel
in any one lowering is a silent wrong-read or a spurious compile error.

## Current state

No cell carries an `.xfail.<mode>` marker. `field-read/*` and `pass-arg/*` pin
the `gen_selector` peel (`27c1ee8b`), and `method/*` the readonly-receiver
dispatch / object-const model (`d3761004`/`408cc533`). The same
wrapper-transparency root, one variant over:

- **`wrapper-order/inner-{managed,raw}-ptr`** — the modifier on the POINTEE
  (`@readonly Box` / `*readonly Box`): `gen_selector` must peel the pointer's
  `.Elem` as well as an OUTER `readonly @Box`, or the read is a silent literal-0.
- **`alias/method-receiver`** — an alias-typed receiver (`type AB = @Box`) must be
  peeled at the method-lookup site (`ReceiverBaseNamed`'s `TYP_ALIAS` arm), or the
  call is a hard compile error.
- **`construct/readonly-iface`** — a concrete value must iface-wrap into a
  `readonly @Iface` target.

## Note (language design vs bug)

Whether `readonly` *permits* non-mutating method calls is a language-design call
(cf. Rust `&self`, C++ const methods). The `method/*` cells assume **yes** (a
non-mutating call should work); if the decision is **no**, they become `.error`
cells instead. The silent wrong field-read is unambiguously a bug regardless.
