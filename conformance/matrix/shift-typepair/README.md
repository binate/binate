# Shift type-pair matrix

The **cross-type shift** member of the conformance matrix family
(`../README.md`). A shift `x << y` / `x >> y` is asymmetric: the count `y` may
be ANY integer type, independent of the value `x`, and the result type is the
VALUE's. This matrix covers the full product of (value-type, count-type).
Coordinate-addressed:

    conformance/matrix/shift-typepair/<op>/<value-type>.bn   (+ .expected)

Generated by `conformance/gen-shift-typepair-matrix.py`. The count-type is the
in-cell sweep dimension (like `scalar-diff/` sweeps values), so each cell tests
one value-type against all ten count-types.

## Axes & assertion

- **op** — `shl` (`<<`) / `shr` (`>>`).
- **value-type** — the left operand's type: `int8/16/32/64`, `int`,
  `uint8/16/32/64`, `uint` (10).
- **count-type** (in-cell sweep) — the right operand's type: the same 10.

Each (value-type, count-type) pair asserts three things:

- **PERMITTED** — the shift compiles for every count type. (It used to be
  rejected when the operand types differed — `int64 << int` in 32-bit-int modes
  — as "mismatched types"; see `claude-todo.md`.)
- **RESULT TYPE = the value's** — the result is bound to `var r <value-type>`
  with NO cast. A result widened to the (wider) count's type would be a
  narrowing assignment and fail to COMPILE, so a cell that compiles already
  proves the result is no wider than the value.
- **VALUE** — correct at the value's width: a small in-range case (`3 << 2`,
  `12 >> 2`), plus — for fixed-width value types — an overshift at the value
  width that pins the result WIDTH (overshift yields 0 for `<<` / logical `>>`,
  sign-fill for arithmetic `>>`; a wider-typed result would not).

Every line is a target-stable `testing.Println(bi(<computed> == <spec>))` -> 1. The
target-width value types (`int` / `uint`) skip the overshift-width check (its
result depends on the target int size); they still assert permitted +
result-type + small value.

## Current state

All cells pass on `builder-comp`, `builder-comp-int`, and `builder-comp-comp`.
The matrix is the coverage layer behind the point regression
`regressions/shift-count-any-int-type` and the unit test
`pkg/binate/types TestCheckShiftMixedCountType` (binate `fd3cb7ac`).
